Par ou Ímpar
Um programa simples em Python que verifica se um número é par ou ímpar.

Sobre
Este projeto foi criado para praticar conceitos básicos de programação e o uso do operador módulo.

Como Funciona
O programa solicita que o usuário informe um número.

Em seguida, utiliza o operador módulo (%) para verificar se o número é divisível por 2.

Se o resto for 0, o número é par.

Caso contrário, o número é ímpar.

Tecnologias
Python

Como Executar
Clone o repositório:

git clone https://github.com/SEU-USUARIO/even-or-odd.git

Entre na pasta do projeto:

cd par-ou-ímpar

Execute o programa:

python main.py

Exemplo
Digite um número: 10

10 é par.

Outro exemplo:

Digite um número: 7

7 é ímpar.
